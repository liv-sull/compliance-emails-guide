# Compliance emails guide

Step-by-step guide the learning team follows each quarter to build the compliance reminder emails for people leaders.

It's a single page, `index.html`, served by GitHub Pages and embedded in Confluence.

## Updating the steps

All the steps live in `index.html`, in the `STEPS` list inside the script near the bottom. Each step has a title and a list of checks. Edit the text there and commit to `main`. The live page updates in a minute or two.

- **The Copilot prompt** is in `promptText()`. The old financial years it leaves out are worked out from the year entered on the page, so it doesn't need changing each year.
- **The Copilot link** is `COPILOT_URL` at the top of the script.

## Saved progress

Ticks and numbers are saved in each person's browser, per quarter. Nothing is sent anywhere. Clearing browser data clears them.
